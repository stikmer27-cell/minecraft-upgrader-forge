# Changelog

## 1.1 (2026-08-21)

- Rebuilt the interface around a darker casino layout with a bright upgrade wheel, raised panels and clear target/wager cards.
- Restored the original `x2`, `x4`, `x8`, `30%`, `50%` and `70%` upgrade presets.
- Added a separate 1 to 64 quantity window for stackable rewards.
- Added searchable item and enchanted-book catalogues with value, chance and equipment statistics.
- Reworked recipe and modded-item valuation; closed storage-block, cosmetic-NBT and cheap-crafting value loops.
- Added server-side processing locks, unique attempt IDs and replay protection.
- Fixed duplicate rewards, double charges, full-inventory handling and rewards returning to the wager slot.
- Added original interface sounds, smooth wheel motion and lightweight victory fireworks.
- Blocked technical, creative-only and unobtainable rewards.
- Improved performance by paging the catalogue and caching item descriptions, values and configuration.
